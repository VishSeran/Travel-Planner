# Travel-Planner
This simple project applied concepts of Java date manipulation by creating a travel planner application. This project-built functionality that helps users plan their trips rips by:

1. Calculating the duration of trips between departure and return dates
2. Validating that travel dates are valid and logical
3. Computing check-in and check-out dates based on arrival dates
4. Determining if trips overlap with holidays or special events

This practical challenge reinforces key concepts from the date manipulation lab including:

1. Using LocalDate, Period, and ChronoUnit for date operations
2. Validating user input dates
3. Calculating differences between dates
4. Adding or subtracting time periods from dates
